# Roadmap

A direction, not a commitment: entries carry no dates. The issues are the detail; the
tracking issue lists the v1 slices.

## Now

- **v1: chat with AI personas** (integration branch `feat/v1`). The team gets:
  - invited accounts with the admin and member roles, no public sign-up;
  - personas of their own, shared with the team, and a featured catalogue the admin curates;
  - conversations with Claude or a local model, picked per conversation, the local ones
    shown offline when the Mac is off;
  - streamed replies that survive a lost connection, edit and regenerate with branches,
    search, export as Markdown or JSON;
  - attachments and vision, projects whose documents the persona can search (RAG), web
    search, MCP tools whose every write is confirmed, artifacts;
  - long-term memory per persona that each member can read and edit;
  - reactions, pins, a typing state, push notifications and voice (speech to text, text
    to speech);
  - a monthly budget per member with an alert at 80 % and a stop at 100 % for paid
    models, and team usage figures for the admin, who never reads members' conversations.

## Next

- **v1.1: persona groups**: a conversation with several personas, each answering in turn
  or when named, with its own model, tools and memory.

## Later

- **v2: humans**: messaging between members and groups that mix members and personas.
- Proactive messages from a persona (reminders, follow-ups).

## Not planned

- Public sign-up or several tenants: ruxia serves one invited team.
- Admin access to members' conversations.

Nothing yet.
